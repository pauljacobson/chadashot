### Feed media and lightbox mockups

These mockups explore a wider article reading area, inline media constrained to the article content width, and a full-window enlarged-media overlay.

#### Option A — Balanced

- Approximately 840 px reading column.
- Media aligns directly with the article text.
- Minimal dimmed overlay with a prominent close control.

#### Option B — Framed viewer

- Approximately 900 px reading column.
- Media sits in a subtle figure frame with a caption.
- Enlarged media opens in a framed viewer over a softly blurred app.

#### Option C — Immersive

- Responsive reading column around 880 px on a large desktop window.
- A centered “View larger” affordance appears over media on hover.
- Enlarged media uses a near-full-window overlay with a slim title bar.

These are design explorations, not implementation screenshots. Exact sizing and behavior should be confirmed before development.
